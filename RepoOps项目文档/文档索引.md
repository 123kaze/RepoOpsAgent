# RepoOps 项目文档索引

这个目录集中保存 RepoOps Agent 的中文项目材料。仓库根目录的 `README.md` 作为
GitHub 项目首页按惯例保留，没有移动。

## 推荐阅读顺序

1. [项目首页与快速开始](../README.md)：项目定位、架构、快速启动和简历口径。
2. [优化复测结论](优化复测结论.md)：当前最终指标、优化内容、无效 run 与简历口径。
3. [开发实现报告](开发实现报告.md)：实现了哪些工具、安全边界、状态和测试。
4. [项目评估报告](项目评估报告.md)：20 条 Python 历史集、跨语言正式集与演示结果。
5. [RepoOps 与 Claude Code 对照评测报告](RepoOps与Claude-Code对照评测报告.md)：
   同一 DeepSeek V4 Pro 下的完整系统对照、逐题结果与局限。
6. [Claude Code 对照测试方法](Claude-Code对照测试方法.md)：测试环境、命令、轨迹
   采集、评分方法和复现步骤。
7. [跨语言多仓库对照评测报告](跨语言多仓库对照评测报告.md)：Go、TypeScript、Rust
   三仓库 15 条 pre-fix 任务的 RepoOps / Claude Code 正式对照。
8. [真实历史任务集说明](真实历史任务集说明.md)：数据来源、标签、固定快照和指标边界。
9. [失败案例与风险清单](失败案例与风险清单.md)：已经遇到的 Agent、安全和评测问题。
10. [源码学习与设计笔记](源码学习与设计笔记.md)：nanobot 核心设计与 RepoOps 的扩展方式。

## 面试时优先使用

- 项目介绍：根目录 [README](../README.md)。
- 数据真实性与最终指标：[优化复测结论](优化复测结论.md)和
  [项目评估报告](项目评估报告.md)。
- 为什么不是 Skill：[RepoOps 与 Claude Code 对照评测报告](RepoOps与Claude-Code对照评测报告.md)
  中的对应章节。
- 为什么优于通用代码 Agent：[Claude Code 对照测试方法](Claude-Code对照测试方法.md)
  和[跨语言多仓库对照评测报告](跨语言多仓库对照评测报告.md)。
- 被追问失败案例：[失败案例与风险清单](失败案例与风险清单.md)。
